# Design System — Linqibin Blog

## Concept

**朱印开卷**：浅色国风技术博客。冷灰纸面、朱红印章、暗金细线——明亮可读，仍有仪式感。

## Signature

朱红方印「林」+ 暗金细线。开屏落印与首屏金线拉开是记忆点。

## Anti-patterns

- 不做深色墨夜底、奶油纸 + 陶土色、紫色渐变
- 不用网格底、套准外框、时间轴圆点
- 不堆英文装饰标签

## Color

| Token | Hex | Role |
| --- | --- | --- |
| `--paper` | `#F2F4F7` | 冷灰纸面 |
| `--ink` | `#14181F` | 主文字 |
| `--mist` | `#667085` | 次级文字 |
| `--line` | `#D4DAE3` | 分割线 |
| `--seal` | `#D92D20` | 朱印 |
| `--seal-soft` | `#F8E4E2` | 轻强调底 |
| `--gold` | `#B8923F` | 暗金线 |
| `--warn` | `#B42318` | 错误 |

## Typography

- **品牌 / 标题**：Noto Serif SC
- **正文 / UI**：Noto Sans SC

## Layout

- 首屏：品牌 + 一句说明 + 金线，无卡片无统计
- 列表：细线分隔，悬停朱红竖线
- 正文：约 65ch 行宽
